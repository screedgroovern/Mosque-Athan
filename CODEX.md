# MosqueAthan

Android TV mosque prayer schedule application built with Kotlin and Jetpack Compose.

## App Name
MosqueAthan

## Package Name
com.groovernapp.mosqueathan

## Target Device
Android TV (Landscape)

## Coordinates
Latitude: -7.713585464212388
Longitude: 110.37963165899664

## Prayer Rules
Show:
- Subuh
- Syuruq
- Dzuhur
- Ashar
- Maghrib
- Isya

Syuruq is informational only and must never become the next prayer.

## UI Rules
- Landscape only
- Masjidil Haram background
- Large center clock
- Gregorian date
- Hijri date
- Horizontal prayer schedule
- Running text at bottom
- Header format: DZUHUR • 01:23:45

## Architecture
- Kotlin
- Jetpack Compose
- Realm Kotlin
- Adhan2
- UiState based screen state
- DashboardUiState
- IqomahUiState
- AdzanUiState

## Future Features
- Adzan screen
- Iqomah screen
- Realm settings
- Running text configuration
- Audio support
